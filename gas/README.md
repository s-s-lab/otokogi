# 男気録 共有バックエンド

Google Apps Script（GAS）で、共有URLごとのグループデータをGoogleスプレッドシートへ保存します。

## 初回設定

1. 対象スプレッドシートを開く
2. 「拡張機能」→「Apps Script」
3. `Code.gs` の内容を貼り付けて保存
4. 「デプロイ」→「新しいデプロイ」→「ウェブアプリ」
5. 実行ユーザーを「自分」、アクセスできるユーザーを「全員」に設定
6. デプロイ後の `/exec` URLをフロントエンドの `public/config.js` に設定

スプレッドシートIDとタブ構造は、現在の「男気録_共有データ」に合わせて設定済みです。
