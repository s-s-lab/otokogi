# 男気録 — OTOKOGI LOG

男気じゃんけんの勝負を、グループごとに楽しく記録するWebアプリです。

## 主な機能

- グループの作成とメンバー管理
- 勝負の内容、日付、参加者、男気を見せた人の記録
- おやつ・ドリンク・ごはん・大勝負によるポイント制
- ポイントランキングと、男気レベルに応じて成長するイラスト
- 内容・メンバー名・カテゴリによる過去の勝負検索
- スマートフォン対応
- グループ専用URLによる共同閲覧・共同更新
- Google Apps ScriptとGoogleスプレッドシートへの共有保存
- 30秒ごと・画面復帰時の自動同期
- 更新履歴の自動バックアップ
- 旧ブラウザ保存データの共有データへの移行

## 開発

```bash
npm install
npm run dev
```

## テスト・ビルド

```bash
npm test
npm run lint
npm run build
```

## 共有バックエンド

GASコードは `gas/` にあります。対象スプレッドシートのApps Scriptへ
`gas/Code.gs` を設定し、ウェブアプリとして公開したURLを
`public/config.js` の `apiUrl` に設定してください。

共有URLは十分に長いランダムキーを含みます。アカウント登録は不要ですが、
URLを知っている人はグループの閲覧・更新ができるため、公開場所への掲載は避けてください。
