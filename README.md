# 男気録 — OTOKOGI LOG

男気じゃんけんの勝負を、グループごとに楽しく記録するWebアプリです。

## 主な機能

- グループの作成とメンバー管理
- 勝負の内容、日付、参加者、男気を見せた人の記録
- おやつ・ドリンク・ごはん・大勝負によるポイント制
- ポイントランキングと、男気レベルに応じて成長するイラスト
- 内容・メンバー名・カテゴリによる過去の勝負検索
- スマートフォン対応
- ブラウザのローカルストレージへの自動保存

## 開発

```bash
npm install
npm run dev
```

## テスト・ビルド

```bash
npm test
npm run lint
npm run build
```

## データについて

記録はブラウザの `localStorage` に保存されます。初回起動時は画面を確認できるよう、サンプルグループと勝負記録が表示されます。グループ管理画面から削除し、実際のグループを作成できます。
